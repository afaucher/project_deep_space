Right now we will fire at each PD target with each weapon before checking the next.  This is wildly backwards in terms of engagement priority.  We should be prioritizing targets that are closest to us, that we think pose a threat.

One strategy would be sort by:
* Times-we-fired-at-already (ascending)
* Range (ascending)

This would give you priority for the target you hadn't tried to shoot yet, then the closest.  This seems better because we get almost no feedback if we hit.  So we would want to spread our shots around a bit more.

Additionally, we should pick the shortest range laser to fire that is ready.  This lets us save the long range lasers for the targets that are farther away.
