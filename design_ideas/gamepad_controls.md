# Gamepad Controls (Milestone Spec)

This document outlines the planned gamepad control scheme for both menu navigation and in-game ship operation.

## Main Menu
* **A Button:** Start Singleplayer

## In-Game Controls

### Navigation & Movement
* **Left Stick (L/R):** Adjust Heading (Steering)
* **Left Stick (Up/Down):** Adjust Throttle / Target Velocity
* **Left Stick (Click/L3):** Toggle Linear Mode (Switch between Throttle vs. Velocity control)
* **Right Stick (Up/Down):** Adjust Nav Panel Zoom

### Combat & Sensors
* **Right Trigger (RT):** Fire all ready weapons
* **Right Bumper (RB):** Cycle Next Contact (Next closest)
* **Left Bumper (LB):** Cycle Previous Contact (Next furthest)

### Toggles & Debug (Face Buttons)
* **Y Button:** Toggle Ship-Oriented vs. North-Oriented Map
* **X Button:** Toggle Combat Steering Mode
* **B Button:** Spawn Enemy (Debug/Testing)
* **A Button:** *[Unassigned]*

### System
* **Start / Xbox / Options:** Exit the game
